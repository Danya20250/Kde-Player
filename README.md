## ✨ Features

- 🌊 **Wavy progress bar** — the played portion of the track undulates like a sine wave, Material 3 Expressive style
- 🎨 **Aurora background** — soft floating blobs that shift color based on the current track's artwork
- 🖼 **Artwork color extraction** — automatically pulls dominant colors from the cover and brightens them for readability
- 🎚 **Seek by click** — click anywhere on the progress bar to jump
- ⏯ **Full MPRIS control** — play/pause, previous, next, and position via `playerctl`
- 🪟 **Frameless glass UI** — translucent capsule with rounded corners, blending into any wallpaper
- 🎯 **Vertical pill thumb** — a rounded vertical bar instead of the classic circular knob
- ⚡ **Lightweight** — pure QML, no Python, no external daemons
